# 👻 GHOST — نظام الشبح لـ Delta Force (iOS)

## نظرة عامة
استقلال كامل عن لودر BTGAMING: الهاك (Lua 5.3 bytecode) يُلصق مباشرةً في مجلد
`Saved/LuaSource` أثناء **تحميل موارد الماتش** — اللحظة التي تسبق/تتجاوز مسح اللعبة
للملفات الغريبة، فيحمّله الـ hot-reload الرسمي داخل Lua VM اللعبة.

## المكونات
| الملف | الوظيفة |
|---|---|
| `luasource_ghost.bin` | هاك منقّح البصمات (ZAINIOS8) — ترخيصه الداخلي سليم حتى 2027-10-30 |
| `ghostpaste.py` | أداة اللصق الذكية (اكتشاف تلقائي لحاوية اللعبة) |

## التثبيت
1. ثبّت `luasource_ghost.bin` في `/var/mobile/Documents/`
2. انسخ `ghostpaste.py` للجهاز (Filza/SSH)
3. (مرة واحدة) سوِّ باتشاً أخيراً باللودر ثم: `python3 ghostpaste.py setup`
4. عطّل Tweak Injection للعبة من إعدادات Dopamine ← **طبقة الشبح الأساسية**

## الاستخدام (الوصفة الذهبية)
1. افتح اللعبة ← ادخل ماتش ← شاشة **تحميل الموارد**
2. أثناء التحميل: `python3 ghostpaste.py now`
3. استنى إشعار/رجوع للعبة ← القائمة مع فتح الماتش ✅

## طبقات الحماية
1. **صفر حقن** باللعبة (Dopamine per-app) — عملية نظيفة 100%
2. **بصمات مُنقّحة** — لا BTGAMING/dongdong (salt الترخيص محفوظ وظيفياً)
3. **بصمة الجهاز**: إعادة تعيين IDFV (حذف/تثبيت تطبيقات Garena) عند تغيّر الحظر
4. **سلوك**: ESP عقلاني — لا قنص فاضح، تنويع باللعب
5. **Dopamine Hide-Jailbreak**: فعّله خارج أوقات اللعب
