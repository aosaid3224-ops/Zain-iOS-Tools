
# iOS Jailbreak Tools

مستودع يضم مجموعة من الأدوات والمشاريع المخصصة لنظام iOS وبيئات Jailbreak.

يهدف المستودع إلى توفير أدوات عملية لإدارة التطبيقات وبيانات النظام، إلى جانب مشاريع وأدوات وانواع أخرى يتم تطويرها وإضافتها بشكل مستمر.
وايضا يتضمن عدة ادوات ومنها Spaider الاصليه ب اسم ipainstaller pro
ونسخه اخرى اخره منها ممستقله مخصوصه لبيئه Relaxin\Roothide ب اسم spaider roothide

## Tools

### AppData Manager اول اداه تم تطويرها في المستودع 

أداة لإدارة بيانات التطبيقات على أجهزة iOS، وتشمل:
* عرض التطبيقات ومعلوماتها.
* حساب أحجام بيانات التطبيقات.
* حذف بيانات التطبيقات.
* إنشاء واستعادة النسخ الاحتياطية.
* إدارة النسخ الاحتياطية.
* البحث بالاسم أو Bundle ID.

*المستودع يتضمن أدوات ومشاريع أخرى، وسيتم تحديث القائمة مع إضافة مشاريع جديدة.*
